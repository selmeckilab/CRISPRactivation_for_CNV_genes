# CRISPRactivation_for_CNV_genes
This repository contains all code and metadata files for Vande Zande et al, 2026

All scripts are listed below along with a description of what raw data and metadata or processed data files are necessary as input, and what figures are generated in each script, if applicable. Raw fastq files for whole genome sequencing and all bar-seq experiments are available at SRA accession PRJNA1506084.
